## Format

One file per decision: `docs/adr/NNNN-short-title.md`.

### Template

```markdown
# NNNN. Title

**Status:** Proposed | Accepted | Deprecated | Superseded by ADR-NNNN
**Date:** YYYY-MM-DD
**Issue:** #N (if any)

## Context
## Decision
## Consequences
```
