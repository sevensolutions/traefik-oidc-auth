# AI Policy of traefik-oidc-auth

To maintain a high quality of contributions to the *traefik-oidc-auth* project, we provide the following guidance on the use of *Generative Artificial Intelligence*, including large language models (LLMs), GitHub Copilot, Codex, Claude code, or similar tools (*Generative AI*).
The guidance in this document is intended for all contributors to the community.

## Overall

The code you submit with a PR is **your** code. You are fully responsible for your submission.

## Acceptable Use

- Using AI to speed up boilerplate, write or extend tests, refactor code you already understand, or explain unfamiliar parts of the codebase.
- Using AI for a first draft implementation you then manually review, rewrite where necessary and fully understand.
- Using AI-powered autocomplete (e.g. GitHub Copilot) for small, line-by-line suggestions that you read and understand before accepting.
- Using AI to review your own diff before opening a PR, as an addition to (not a replacement for) your own review.

**In all of these cases, you must be able to fully explain, defend, and maintain every line you submit, as if you had written it yourself without any assistance.**

## Unacceptable Use

- Submitting AI-generated code, tests, or documentation that you have not personally reviewed, understood, and verified to be correct, secure, and consistent with the project's conventions.
- Using AI to generate large parts of a feature or PR end-to-end without meaningful human design and review, especially for security-sensitive areas.
- Copy-pasting answers from a chatbot or AI tool without adapting them to this project's architecture, style, and requirements.
- Using AI to fabricate or embellish claims in a PR or issue, e.g. describing testing that was not actually performed, or benchmarks that were not actually run.
- Using AI to mass-produce low-effort issues or PRs ("AI slop").
- Pasting proprietary, confidential, or sensitive information (including secrets, tokens, or private user data) into third-party AI tools.

## Transparency & Attribution

- You don't need to call out routine, small-scale AI assistance (e.g. autocomplete suggestions, minor wording help).
- For contributions where AI was used to generate a significant portion of the code, tests, or documentation, please mention this in the PR description, along with the tool(s) used. This helps reviewers calibrate their review and isn't a judgment on the quality of your contribution.
- Be prepared to answer questions about the design and implementation details of your submission during review. "The AI wrote it that way" is not an acceptable answer to a review comment. You are expected to understand and be able to justify your own code.
